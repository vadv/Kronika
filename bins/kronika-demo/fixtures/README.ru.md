# Запись демо для GitHub Pages

[English version](README.md)

`github-pages-hour.zms` — фиксированные входные данные для штатного отчёта
Kronika на GitHub Pages. Файл содержит 20 минут синтетических данных Linux,
PostgreSQL и PgBouncer с публичным именем хоста `kronika-demo`: короткие
параллельные торговые транзакции, ожидания блокировок, планы запросов и
ограниченную нагрузку на CPU, память, диск и сеть. Штатный инструмент создал
самостоятельный ZMS:

```sh
KRONIKA_STORAGE_DIR=CAPTURE kronika-dump slice \
  --from 2026-09-05T15:32:00Z \
  --to 2026-09-05T15:51:59Z \
  --out github-pages-hour.zms
```

Границы включаются с точностью до целой секунды и задают полуинтервал
`[15:32:00, 15:52:00)` длиной ровно 1 200 000 000 микросекунд. Штатная нарезка
может сохранить ближайшие снимки за границами интервала. Отчёт использует
явные границы из `github-pages-hour.slice`; шкала времени показывает
календарный час 15:00–16:00.

Время и счётчики живой записи зависят от момента запуска, поэтому CI использует
этот ZMS как фиксированные входные данные. `scripts/build-pages-report.sh`
проверяет его SHA-256, передаёт файл и диапазон в `kronika-report`, проверяет
встроенные границы, побайтно сравнивает два созданных HTML-файла и запускает
результат с диска в Chromium.
