# Запись демо для GitHub Pages

[English version](README.md)

`github-pages-hour.zms` — фиксированные входные данные для штатного отчёта
Kronika на GitHub Pages. Образ демо из репозитория записал синтетические данные
Linux, PostgreSQL и PgBouncer с публичным именем хоста `kronika-demo`. Затем
штатный инструмент создал самостоятельный ZMS:

```sh
KRONIKA_STORAGE_DIR=CAPTURE kronika-dump slice \
  --from 2026-09-04T12:00:00Z \
  --to 2026-09-04T12:59:59Z \
  --out github-pages-hour.zms
```

Границы включаются с точностью до целой секунды и задают полуинтервал
`[12:00:00, 13:00:00)` длиной ровно 3 600 000 000 микросекунд. Штатная нарезка
может сохранить ближайший снимок перед запрошенным интервалом. Исходная запись
заканчивается до следующего часа, поэтому отчёт открывает запрошенный час.

Время и счётчики живой записи зависят от момента запуска, поэтому CI использует
этот ZMS как фиксированные входные данные. `scripts/build-pages-report.sh`
проверяет его SHA-256, передаёт именно этот файл в `kronika-report`, побайтно
сравнивает два созданных HTML-файла и запускает результат с диска в Chromium.
